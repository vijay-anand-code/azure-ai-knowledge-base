# Monitoring Runbook

**File:** `runbook_monitoring.py`
**Runtime:** Python 3.10 — Azure Automation Account
**Schedule:** Weekly Monday 00:30

Triggers the secret monitoring cycle with a POST to `AGENT_ENDPOINT`. In the current
deployment this is pointed directly at Container 2, bypassing Container 1's LangChain agent,
since a scheduled trigger needs no reasoning step and this avoids GPT-4o cost and rate limits.
