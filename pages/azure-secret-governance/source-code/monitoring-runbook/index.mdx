# Monitoring Runbook

**File:** `runbook_monitoring.py` (on disk: `devsecops-secret-governance-monitor-langchain.py`)
**Runtime:** Python 3.10 — Azure Automation Account
**Schedule:** Weekly Monday 00:30

Triggers the secret monitoring cycle with a POST to `AGENT_ENDPOINT`, which points at Container
1's `/run` endpoint. Container 1's LangChain agent picks up the instruction and calls its
`run_secret_monitoring` tool, which forwards the actual work internally to Container 2's
`/tools/run_secret_monitoring`. The runbook itself is a thin fire-and-forget trigger — the real
classification, ticket, and alert logic all lives in Container 2's `decision_engine.py`.
