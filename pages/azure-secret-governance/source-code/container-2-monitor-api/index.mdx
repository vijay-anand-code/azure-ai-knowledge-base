# Container 2 — Monitor REST API

**Runtime:** Python 3.11 — Azure Container App (port 8001, internal only)
**Called by:** Container 1 LangChain agent tools

Internal REST API that implements all tool operations — no AI, no LangChain.
Container 1 calls these endpoints to interact with Entra ID, SharePoint, Jira,
and Teams.

| File | Purpose |
|------|---------|
| [main.py](/azure-secret-governance/source-code/container-2-monitor-api/container2-main) | FastAPI app — all tool implementations and HTTP endpoints |
| [decision_engine.py](/azure-secret-governance/source-code/container-2-monitor-api/container2-decision-engine) | Async orchestrator — classifies secrets, raises tickets, sends alerts |
