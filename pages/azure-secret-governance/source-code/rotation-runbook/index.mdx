# Rotation Runbook

**File:** `runbook_rotation.py`
**Runtime:** Python 3.10 — Azure Automation Account
**Schedule:** Weekly Monday 01:00

Rotates expiring secrets for owned App Registrations in two phases — first
checks if existing rotations are complete (Phase A), then proactively rotates
P1/P2/P3 secrets (Phase B). New values stored in Key Vault, Jira updated with
retrieval instructions.
