# Container 1 — LangChain Agent

**Runtime:** Python 3.11 — Azure Container App (port 8000, public)
**Triggered by:** Monitoring runbook, Jira webhooks, Teams Bot messages

The public-facing container. Hosts a LangChain agent (GPT-4o) that orchestrates
the governance cycle by calling tools on Container 2. Also handles the Teams Bot
and Jira webhook integrations.

| File | Purpose |
|------|---------|
| [main.py](/azure-secret-governance/source-code/container-1-langchain-agent/container1-main) | FastAPI app — LangChain agent, all tool definitions, endpoints |
| [teams_bot.py](/azure-secret-governance/source-code/container-1-langchain-agent/container1-teams-bot) | Standalone Teams Bot module — receives and replies to Teams messages |
