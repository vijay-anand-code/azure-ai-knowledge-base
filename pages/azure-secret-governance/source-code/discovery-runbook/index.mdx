# Discovery Runbook

**File:** `runbook_discovery.py`
**Runtime:** Python 3.10 — Azure Automation Account
**Schedule:** Weekly Monday 00:00

Scans ALL App Registrations from Entra ID, fetches their owners in parallel,
classifies every secret by severity bucket, and batch-writes rows to the
SecretAlertRegistry SharePoint list.

| File | Purpose |
|------|---------|
| [runbook_discovery.py](/azure-secret-governance/source-code/discovery-runbook/runbook-discovery) | Main discovery runbook — scans all apps and writes to SharePoint |
| [runbook_cleanup_sharepoint.py](/azure-secret-governance/source-code/discovery-runbook/cleanup-sharepoint) | Utility — deletes all SharePoint rows for a fresh test run |
| [count.mdx](/azure-secret-governance/source-code/discovery-runbook/count) | Utility — CLI command to count total App Registrations and secrets via Graph, for cross-checking against runbook output |
