# Excel Bulk Sync

**Runtime:** PowerShell 7+ (Microsoft Graph PowerShell SDK) — run manually from Cloud Shell or a local
terminal, not an Azure Automation runbook.

Creates a new SharePoint item (`POST`) for every row in a CSV. There is no `ID` matching here — this
is only safe to run against a genuinely **empty** list, e.g. right after
`runbook_cleanup_sharepoint.py`. Running it against a populated list would create a duplicate of every
row, since it has no way to know an item already exists.

Refuses to run if it finds any row with a blank `SecretID`, since that's the signature of a common
Excel mistake: pressing `Delete` only clears cell content, it doesn't remove the row. A CSV saved after
clearing (rather than actually deleting) unwanted rows still contains those rows, just blank, and
without this check the script would create an empty SharePoint item for each one.

## Source

```powershell
# --- CONFIG ---
$siteHost   = "copilot365demooutlook.sharepoint.com"
$sitePath   = "/sites/ContosoIT"
$listName   = "SecretAlertRegistry"
$importCsv  = "$HOME/SecretAlertRegistry_Export.csv"   # your full, corrected dataset

$columnsToImport = @(
    "Title","AppName","SecretID","SecretDescription","TeamName","ProductName",
    "ProductTeamkeyVaultName","NewSecretKeyId","NewSecretVaultName","ExpirationDate",
    "AlertStatus","JiraTicketCreatedDate","LastChecked","RotationDetectedDate",
    "JiraTicketKey","AlertSentDate","ExpiryNotice","TenantID","AlertHistory",
    "ExpiryBucket","AppOwners","ManualAppOwners","ObjectID"
)
# --- end config ---

Connect-MgGraph -Scopes "Sites.ReadWrite.All"

$site = Invoke-MgGraphRequest -Method GET -Uri "https://graph.microsoft.com/v1.0/sites/${siteHost}:${sitePath}"
$list = Invoke-MgGraphRequest -Method GET -Uri "https://graph.microsoft.com/v1.0/sites/$($site.id)/lists/$listName"

if (-not (Test-Path $importCsv)) {
    Write-Error "CSV file not found at $importCsv"
    return
}
$csvRows = Import-Csv -Path $importCsv

# --- Safety check: refuse to run if any row is blank (the cause of last time's 1,471 empty items) ---
$blankRows = $csvRows | Where-Object { -not $_.SecretID }
if ($blankRows.Count -gt 0) {
    Write-Host "ABORTING: found $($blankRows.Count) row(s) with no SecretID — these are almost certainly leftover blank rows from Excel (content cleared, row not actually deleted)." -ForegroundColor Red
    Write-Host "Fix by selecting those rows in Excel and right-click -> Delete (not just pressing Delete key), then re-save and re-run." -ForegroundColor Red
    return
}

Write-Host "Loaded $($csvRows.Count) rows from CSV, no blank rows found. Starting import..." -ForegroundColor Cyan

$targetUri = "https://graph.microsoft.com/v1.0/sites/$($site.id)/lists/$($list.id)/items"

$counter = 0
$errors = @()
foreach ($row in $csvRows) {
    $counter++

    $fieldsPayload = @{}
    foreach ($col in $columnsToImport) {
        if ($row.$col) {
            $fieldsPayload[$col] = $row.$col
        }
    }

    $body = @{ fields = $fieldsPayload } | ConvertTo-Json -Depth 10

    try {
        $progress = [Math]::Round(($counter / $csvRows.Count) * 100, 1)
        Write-Host "[$progress%] ($counter/$($csvRows.Count)) Importing SecretID: $($row.SecretID)..." -ForegroundColor Yellow
        $null = Invoke-MgGraphRequest -Method POST -Uri $targetUri -Body $body -ContentType "application/json"
    }
    catch {
        Write-Host "Error importing row $counter (SecretID: $($row.SecretID)): $_" -ForegroundColor Red
        $errors += $row.SecretID
    }
}

Write-Host "Import process finished! $($csvRows.Count - $errors.Count) succeeded, $($errors.Count) failed." -ForegroundColor Green
if ($errors.Count -gt 0) {
    Write-Host "Failed SecretIDs: $($errors -join ', ')" -ForegroundColor Red
}
```
