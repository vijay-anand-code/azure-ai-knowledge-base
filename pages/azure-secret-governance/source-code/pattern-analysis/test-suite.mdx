# Automated Test Suite: Pattern Bypass Governance

**File Location:** `pages/azure-secret-governance/source-code/pattern-analysis/test_pattern_bypass_governance.py`

This test suite executes **16 automated test cases** verifying:
1. **Part 1: Strict Fail-Safe Logic (Unit Tests):** Verifies that if `BYPASS_JIRA_TENANT_IDS` or `BYPASS_JIRA_PATTERNS` are missing, unset, or empty, bypass is completely disabled (`False`). No hardcoded fallback lists exist in the codebase.
2. **Part 2: Multi-Tenant Pattern Isolation:** Verifies glob matching (`*.select*`, `practice-plus-*`, `*partner*`), case insensitivity, comma-separated whitespace handling, and strict tenant isolation (Primary Tenant secrets are never bypassed).
3. **Part 3: Expiry Notice & Bucket Matrix:** Verifies P1..P4 bucket thresholds and formatting of `ExpiryNotice`.
4. **Part 4: Live Azure & Jira Verification (E2E):** Connects to live Microsoft Graph SharePoint list and verifies that:
   - `Test-EnvPattern-Partner-Live` has `AlertStatus: Discovered` and `JiraTicketKey: None`.
   - `Test-EnvStandard-Portal-Live` has `AlertStatus: TeamsAlerted` and `JiraTicketKey: KAN-3367`.
