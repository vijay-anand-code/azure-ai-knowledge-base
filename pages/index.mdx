## New joiner guide

<Callout type="info">
  You don't need to look at the GitHub repo. Everything is documented here — read the pages in order and you'll have the full picture.
</Callout>

<Steps>

### Read the overview for your assigned topic

Each topic's overview explains what it does in plain English before touching any code.

### Follow the sidebar pages in order

Prerequisites before setup, setup before agents. The sidebar order is intentional — don't skip ahead.

### Study the architecture diagram

Every topic has a diagram showing how pieces connect. Build the mental model before reading the detailed docs.

### Read the code examples last

Once you understand the concept, the code section shows real implementation from our repos with line-by-line explanations.

</Steps>

## Adding new content

When the team learns something new, add it here so the next person doesn't start from scratch.

<Callout type="warning">
  To add a new topic, create a new folder under `pages/` with an `index.mdx` and a `_meta.json`. Copy the structure from any existing section. No HTML needed — just plain text with simple formatting.
</Callout>
