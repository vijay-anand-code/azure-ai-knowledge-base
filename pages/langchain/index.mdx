# LangChain

LangChain is the orchestration framework used inside our Azure agents to chain LLM calls, manage
memory, and connect to tools. This section is a general knowledge-transfer reference: what
LangChain actually is, the concepts you need to use it, and how it's concretely used in this
org's own agents, most notably Container 1 of the Azure Secret Governance system, whose full
source is linked throughout as a real, running example rather than a hypothetical one.

## What we use it for

- Building the tool-calling agent behind Container 1 in Azure Secret Governance: scheduled
  governance-cycle triggers, an ad hoc chat endpoint, and a Microsoft Teams bot, all served from
  the same underlying LangChain agent
- Connecting an Azure OpenAI GPT-4o deployment to a set of typed tools that call out to a REST API
- Managing per-session conversation memory across multi-turn chat and Teams conversations
- Building the agent chains inside Azure Multi-Agent Foundry
