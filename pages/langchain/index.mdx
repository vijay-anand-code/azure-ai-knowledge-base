# LangChain

LangChain is the orchestration framework used inside our Azure agents to chain LLM calls, manage memory, and connect to tools.

> **In progress** — This section is being written. Check back soon, or add your notes here if you've been working with LangChain.

## What we use it for

- Building the agent chains inside Azure Multi-Agent Foundry
- Connecting Azure OpenAI models to MCP tools
- Managing conversation memory across multi-turn sessions
