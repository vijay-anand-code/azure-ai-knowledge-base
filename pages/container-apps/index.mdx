# Container Apps

Azure Container Apps is the serverless container platform we use to host our agent APIs and background workers.

> **In progress** — This section is being written. Check back soon, or add your notes here if you've been working with Container Apps.

## What we use it for

- Hosting the `AzureEndToEnd` workflow API endpoint
- Running background agent tasks with scale-to-zero
- Connecting services via Dapr sidecars
